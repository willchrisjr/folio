# Folio — William Trabazo

An editorial personal site: selected work, a short about, a skills index, and a correspondence form.

## Open it

- **Source:** [github.com/willchrisjr/folio](https://github.com/willchrisjr/folio)
- **Preview:** [cdn.jsdelivr.net/gh/willchrisjr/folio@main/index.html](https://cdn.jsdelivr.net/gh/willchrisjr/folio@main/index.html)

To publish on GitHub Pages: **Settings → Pages → Deploy from branch → `main` / root**. The site will then live at `https://willchrisjr.github.io/folio/`.

To publish on Vercel: import this repository as a static site (no build command).

## What’s on the page

- Oversized editorial hero, sticky nav, smooth scroll
- Project cards with hover (or tap) descriptions
- Filter chips: All / Security / Intelligence / AI / Systems
- About, skills taxonomy, contact form, colophon footer
- Responsive down to ~390px; reduced-motion respected
- No accounts, no tracking — notes stay in `localStorage` and open a mail draft

Type: Fraunces + IBM Plex Sans. Paper and ink, one burnt-sienna accent.
